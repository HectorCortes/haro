### Reopen/generation model (bug confirmed)
- **Reopen entry** `internal/execution/state.go:22-119`: builds `toReset={stepID}` plus when `cascade`:

  2. flattened artifact-feeder closure: `producesMap` + `requiresMap`, BFS from `reopenedRequires` over `produces->requires` edges (L50-99). Fine-granularity, ignores composition boundary (constitution X.4) — proven by `cascade_test.go:60-205` (F-06 namespaced `a.p1`/`a.p2`/`b.q` case).

## Risks / Gotchas (strict TDD + invariants)

1. **Spec divergence vs `payload_ref` doctrine** — `docs/v2/haro-especificacion-tecnica.md:228/263` + `deltas-acceptance.md v2-ipc/U-03` state payload never raw / managed outside table. Inline 16 KiB sanitized evidence is not raw, so proposal needs explicit delta-spec amendment (MODIFIED requirement) carving out bounded inline evidence while keeping `payload_ref` for external blobs (snapshots) and backward compat. Without amendment, reviewers will flag as constitution violation.
2. **Idempotent migration race** — `migrate()` runs per `store.Open` connection with `PRAGMA table_info` + `ALTER TABLE`; concurrent opens race on first `payload` column creation must rely on `isDuplicateColumnError` (L217-223) exactly as `dag_hash`/`base_commit` do. Reuse same pattern; add test that opens DB twice concurrently and both succeed.
3. **Backward compat for old executions** — existing `.haro/artifacts/evidence/*.txt` files are obsolete but old `attempt_events` rows with `payload_ref=<path>` remain. Code must continue to handle `payload_ref` read path for old rows (fallback) while new rows use `payload`. `feedback_test.go` and feedback reconstruction must handle both (`payload` preferred, `payload_ref` fallback if `payload==nil`).
4. **Budget semantics after header prepend** — header (`$ argv` or agent metadata) counts against 16 KiB. Implementation must compose header+output then `VisibleEvidence` (not pre-bound output then append header unbounded). Test: `argv` with 10 KiB + output 10 KiB must truncate to exactly 16 KiB, still redacted.
5. **Silent-command fix correctness** — `$ <argv>` ensures non-empty evidence even when `stdout+stderr==""`. Must test: `run: "echo hi > out.txt"` (no stdout) produces evidence == `"$ echo hi > out.txt\n"` (and not empty). Existing E2E in `/home/dev/repos/personal/test` reproduces 0-byte file — convert to RED unit test with `FakeRunner{stdout:"", stderr:""}` asserting `payload` non-empty and starts with `$`.
6. **Agent header budget** — instructions can be large; proposal caps it (e.g., 4 KiB) before joining with output. Must still pass `VisibleEvidence` final cap (16 KiB). Test with oversized instructions (10 KiB) ensures evidence ≤16 KiB and still contains harness/mode/attempt index.
7. **Reopen fix subtlety** — fixing to "latest only" implies that concurrent reopens that invalidate middle generations are not re-introduced; but `InvalidateByStep` `WHERE invalidated_at IS NULL` already marks only valid ones, so after re-run newest gen is valid. Ensure downstream producer reuse of `CurrentGeneration` is monotonic (`Steps().UpdateGeneration` at L489/814). No change to `state.go` invalidation breadth — intentional.
8. **Contract/claim parity** — adding column must not break `contract/suite.go` UNIQUE/cursor/FK checks. Ensure fake parity copies `Payload` alongside `PayloadRef` and `WithTx` copy-on-write covers it (same as `fake.go:616-637` copy logic). Add dedicated `parity_test.go` case that runs suite twice then checks `payload` round-trip.
9. **No filesystem cleanup scope creep** — `v2-evidencia` should *stop writing* evidence files; cleaning old files is optional and can be `RemoveAll(.haro/artifacts/evidence)` guarded behind migration or left for manual GC. Deleting snapshots path is out of scope and dangerous (snapshots are per-produces and currently file-based intentionally).
10. **Adapter manager not wired** — after inline change, real agent evidence will still be synthetic until `SetAdapterManager` is wired in production. Proposal should mark adapter wiring as *declared out-of-scope* with recommendation for follow-up `v2-adapter-wiring` change; otherwise QA will file "agent evidence still synthetic" as regression even though header fix is correct.
11. **Strict TDD cost** — migration + dual-store parity + two evidence formatters + reopen positive path + feedback reconstruction DB path together exceed 400-line single-PR budget if naively batched. Proposal should recommend sliced tasks: slice 1 = `payload` column + migration + parity (small, infrastructure); slice 2 = command+agent evidence headers + feedback DB read + `feedback_test.go` triangulation; slice 3 = reopen latest-generation fix + new positive-path test. Each slice is independently reviewable and reversible.

## Recommended Proposal Angle
